WHAT THIS CYCLE IS ABOUT

After the Exordium demo established that the mod could load and run without crashing, this development cycle focused on building the underlying identity systems that will shape every playthrough. Each of the six cultural groups now has its own religion, its own character names, and a set of culture-level traits that passively define how that faction feels to play.

Alongside that work, the Pictish unit roster is now complete — 20 units covering cavalry, skirmishers, infantry and archers — and a first pass at faction-specific traits has been written for every playable faction, even if many effects are still marked WIP and not yet active in-game. The separatist faction list has also been cleaned up: several placeholder separatists have been replaced with four new, properly-configured factions.

Below is the condensed changelog for dev builds 3 through 7.


CHANGELOG

FACTIONS

  • Fixed Atrebates faction colors
  • Added Atrebates to the frontend faction selection screen
  • All separatist rulers now start with full authority (initial power 100)

REMAINING WORK & KNOWN ISSUES

  • Some battle context bonuses need further testing and tuning
TECHNOLOGIES

UNITS
  • Pictish unit stats are a first pass and need balancing
  • Roman auxiliaries (AOR system) still not implemented
  • Hiberni unit roster is incomplete

FUTURE IMPLEMENTATION

POPULATION SYSTEM

UI
  • Frontend faction selection art is still missing for many Britanni, Galli, Picti and Hiberni factions
  • Many unit cards are still placeholder or missing entirely
RESOURCES
  • Resources are not yet placed on the map — historical placement vs. gameplay balance is still an open design question
