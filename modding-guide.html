CiB MODDING GUIDE
—

01 — Map Editing

Files involved

data/terrain/map.rwm                              ← compiled map, DELETE after any change
data/world/maps/campaign/imperial_campaign/
  map_regions.tga      ← region colour map
  map_heights.tga      ← heightmap
  map_ground_types.tga ← terrain types
  map_climates.tga     ← climate zones
  descr_regions.txt    ← region definitions (name, faction, resource)
  descr_strat.txt      ← starting positions, units on map

Editing regions

Each region is a unique flat colour in map_regions.tga. The RGB value links to an entry in descr_regions.txt.

  1. Open map_regions.tga in Photoshop / GIMP.
  2. Pick a new unique RGB colour (not used by any other region).
  3. Paint the new region with that colour.
  4. Export as 24-bit TGA (no alpha).
  5. Add a matching entry in descr_regions.txt.
  6. Delete map.rwm so the game regenerates it.
descr_regions.txt — entry format
land_region
  name          REGION_NAME
  colour        R G B       ; matches the pixel in map_regions.tga
  settlement    SETTLEMENT_NAME
  faction       faction_key ; starting owner
  resource      resource_key
  religion      religion_key
end
⚠ Always delete map.rwm after any map file change, or the game will load the cached version.

02 — Adding a Faction

Files involved

descr_campaign_db.xml     ← faction list + cultural group assignment
descr_strat.txt           ← starting position on the map
descr_rebel_factions.txt  ← if the faction is a rebel/separatist
ui/faction_flags/         ← faction flag images (.tga)
ui/faction_symbols/       ← small faction icons
text/faction_names.txt    ← localised faction name

Steps

  1. Add the faction entry in descr_campaign_db.xml — set culture, religion, playable.
  2. Add a starting position block in descr_strat.txt with coordinates, settlements, units, characters.
  3. Add the faction name string in the LOC pack.
  4. Add flag images: faction_key.tga in ui/faction_flags/ and ui/faction_symbols/.
  5. If the faction needs a rebel counterpart, add it in descr_rebel_factions.txt.
descr_campaign_db.xml — faction block skeleton
<faction name="faction_key">
  <culture>culture_key</culture>
  <religion>religion_key</religion>
  <playable>true</playable>
  <colour r="R" g="G" b="B"/>
</faction>
⚠ The faction key must be unique and contain no spaces — use underscores: roman_republic.
✔ Playable factions need a complete starting position block with at least one settlement and one general character.

03 — Adding a Cultural Group

Files involved

descr_cultures.txt        ← culture definitions
descr_campaign_db.xml     ← assign factions to the new culture
export_descr_unit.txt     ← units that belong to the culture
descr_building_battle.txt ← building effects per culture
text/culture_names.txt    ← localised culture name

Steps

  1. Add a new entry in descr_cultures.txt.
  2. Add the localised name in the LOC pack.
  3. In export_descr_unit.txt, add ownership lines on each unit that belongs to this culture.
  4. In descr_campaign_db.xml, set <culture>new_culture_key</culture> on each faction.
  5. Create a rebel faction for this culture in descr_rebel_factions.txt.
descr_cultures.txt — entry format
culture culture_key
  tech_tree            tech_tree_key
  building_style       style_key
  portrait_style       portrait_style_key
  rebel_standard_index 0
end

04 — Adding a General Mesh

Files involved

data/models_unit/general_model.cas    ← 3D mesh
data/textures/general_texture.tga     ← diffuse texture
descr_model_battle.txt (DMB)          ← model + texture → unit assignment
export_descr_unit.txt  (EDU)          ← links unit to its DMB entry

Steps

  1. Export the mesh as .cas. The rig must match an existing ToB skeleton (e.g. MTW2_man for infantry, fs_horse_heavy for mounted).
  2. Place .cas in data/models_unit/ and textures in data/textures/.
  3. Add a model entry in descr_model_battle.txt pointing to mesh and texture.
  4. In export_descr_unit.txt, set the general unit's officer line to the new DMB key.
  5. Launch in custom battle first to check for crashes before running campaign.
DMB — model entry skeleton
type         general_model_key
skeleton     MTW2_man          ; or fs_horse_heavy for mounted
indiv_range  40
texture      faction_key, data/textures/general_texture.tga
model        data/models_unit/general_model.cas, 30
model        data/models_unit/general_model_lo.cas, max  ; LOD
EDU — officer line
officer   general_model_key  ; references the DMB type key
⚠ If the skeleton does not match the mesh rig the game will crash on load or show broken animations.
✔ Test with an existing faction general first (copy DMB entry, change only the texture) before swapping the mesh.
