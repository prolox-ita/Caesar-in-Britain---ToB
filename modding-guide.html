01 — MAP EDITING

Files involved

data/
  terrain/
    map.rwm — compiled map (do NOT edit directly)
  world/maps/campaign/imperial_campaign/
    map_regions.tga — region colour map
    map_heights.tga — heightmap
    map_ground_types.tga — terrain types
    map_climates.tga — climate zones
    map_fog_of_war.tga — FoW overlay
    descr_regions.txt — region definitions (name, faction, resource)
    descr_strat.txt — starting positions, faction start, units on map

Editing regions (colour map)

Each region is a unique flat colour in map_regions.tga. The colour value links to an entry in descr_regions.txt.

  1. Open map_regions.tga in Photoshop / GIMP.
  2. Pick a new unique RGB colour (not already used by any other region).
  3. Paint the new region area with that colour on the correct layer.
  4. Export as 24-bit TGA (no alpha).
  5. Add a matching entry in descr_regions.txt — see format below.
  6. Delete map.rwm so the game regenerates it on next launch.
descr_regions.txt — entry format 
land_region
  name          REGION_NAME
  colour        R G B          ; matches the pixel colour in map_regions.tga
  settlement    SETTLEMENT_NAME
  faction       faction_key    ; starting owner
  resource      resource_key   ; optional
  religion      religion_key
end

Adding a new settlement

  1. Add the region entry in descr_regions.txt (above).
  2. Place the settlement icon in descr_strat.txt with coordinates.
  3. Add localisation string for the settlement name in the LOC pack.
  4. Assign the settlement to a province if using the province system.
⚠ Always delete map.rwm after any map file change, otherwise the game uses the cached version.
ℹ Sea regions use the same system as land regions but with the sea_region keyword in descr_regions.txt.
02 — ADDING A FACTION

Files involved

data/
  descr_campaign_db.xml — faction list + cultural group assignment
  descr_strat.txt — starting position on the map
  descr_rebel_factions.txt — if the faction is a rebel/separatist
  ui/
    faction_flags/ — faction flag images
    faction_symbols/ — small faction icons
  text/
    faction_names.txt — localised faction name

Steps

  1. Add the faction entry in descr_campaign_db.xml — set culture, religion, playable (true/false), and other attributes.
  2. Add a starting position block in descr_strat.txt — coordinates, starting settlements, starting units, starting characters.
  3. Add the faction name string in the localisation pack (faction_names.txt or relevant LOC file).
  4. Add flag images: faction_key.tga in ui/faction_flags/ and ui/faction_symbols/.
  5. If the faction needs a separatist rebel counterpart, add it in descr_rebel_factions.txt.
descr_campaign_db.xml — faction block skeleton 
<faction name="faction_key">
  <culture>culture_key</culture>
  <religion>religion_key</religion>
  <playable>true</playable>
  <colour r="R" g="G" b="B"/>
  <!-- add other faction attributes as needed -->
</faction>
descr_strat.txt — starting block skeleton 
faction     faction_key
  ai_label  attacker   ; or defender
  unit      unit_key ; starting units (optional)
  ...
end
✔ Playable factions need a complete starting position block with at least one settlement and one general character.
⚠ The faction key must be unique and contain no spaces. Use underscores: roman_republic.
03 — ADDING A CULTURAL GROUP

Files involved

data/
  descr_cultures.txt — culture definitions
  descr_campaign_db.xml — assign factions to the new culture
  export_descr_unit.txt (EDU) — units that belong to the culture
  descr_building_battle.txt — building effects per culture
  text/
    culture_names.txt — localised culture name

Steps

  1. Add a new entry in descr_cultures.txt — set the culture key, tech tree, building levels, and any culture-specific modifiers.
  2. Add the localised name in the LOC pack.
  3. In export_descr_unit.txt, add ownership lines on each unit that belongs to this culture (or create new units — see unit guide if needed).
  4. In descr_campaign_db.xml, set <culture>new_culture_key</culture> on each faction that should belong to this group.
  5. Add building effects in descr_building_battle.txt if the culture has unique buildings.
  6. Create a rebel faction for this culture in descr_rebel_factions.txt.
descr_cultures.txt — entry format 
culture culture_key
  tech_tree            tech_tree_key
  building_style       style_key
  portrait_style       portrait_style_key
  rebel_standard_index 0
end
ℹ A cultural group typically needs: its own rebel faction, at least one playable faction, and at least a basic unit roster in EDU.
04 — ADDING A GENERAL MESH

Files involved

data/
  models_unit/
    general_model.cas — 3D mesh file
  textures/
    general_texture.tga — diffuse texture
    general_texture_normal.tga — normal map (optional)
  descr_model_battle.txt (DMB) — model + texture → unit assignment
  export_descr_unit.txt (EDU) — links unit to its DMB entry
  animations/
    … — skeleton must match the mesh rig

Steps

  1. Export the general mesh as a .cas file from your 3D tool. The rig/skeleton must match an existing ToB skeleton (e.g. fs_horse_heavy for a mounted general, MTW2_man for infantry).
  2. Place the .cas in data/models_unit/ and textures in data/textures/.
  3. Add a new model entry in descr_model_battle.txt pointing to the mesh and texture.
  4. In export_descr_unit.txt, find the general unit and set its soldier / officer line to reference the new DMB entry.
  5. Assign a faction-specific variant in DMB using faction_override blocks if you want different meshes per faction.
  6. Launch the game in custom battle mode first to check for crashes before running a campaign.
DMB — model entry skeleton 
type         general_model_key
skeleton     MTW2_man           ; or fs_horse_heavy for mounted
indiv_range  40
texture      faction_key, data/textures/general_texture.tga
model        data/models_unit/general_model.cas, 30
model        data/models_unit/general_model_lo.cas, max  ; LOD (low-poly version)
EDU — officer / general line 
officer   general_model_key  ; references the DMB type key
⚠ If the skeleton does not match the mesh rig, the game will crash on load or show broken animations.
✔ Test with an existing faction general first (copy the DMB entry, change only the texture) to verify the pipeline before swapping the mesh.
